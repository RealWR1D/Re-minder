# Re:minder 0.2.0

适用于 Windows 11 x64，内含 .NET 与 Windows App SDK 运行库，无需管理员权限。

## 开始使用

把整个文件夹放在固定位置，双击 **ReMinder.exe**。请保留旁边的 DLL、Assets 和运行库文件。第一次启动没有示例任务。

也可以在 PowerShell 中运行 `Install.ps1`，安装到当前用户的 `%LOCALAPPDATA%\Programs\ReMinder`，并创建开始菜单快捷方式。更新前先从托盘退出应用；不要只替换 EXE。此开发版本未做代码签名。

## 每天使用

- 面板“新建任务”或 **Ctrl+N** 添加任务；点击任务卡片编辑。
- 连续打开其他任务会复用同一个编辑窗口，并先自动保存当前修改。保存成功后切换；输入不完整、任务被其他操作更新或保存失败时，保留当前表单并显示原因。
- 编辑窗口首次打开时与桌面面板的可见顶部对齐；高表单在窗口内滚动，保存/取消固定在底部，切换任务保留窗口位置。
- 右侧滑块可直接拖动；滚轮平滑上下滚动，连续滚动和反向滚动会接续当前位置。设置中的“减少动态效果”可关闭这些过渡。
- 输入名称、日期和 24 小时制时间；“今天/明天/一周后”保留当前时间。“提前分钟数”支持逗号分隔。
- **Enter** 保存；在备注中 **Ctrl+Enter** 保存；**Esc** 关闭，有修改时会确认。
- 日历弹出后，可点击日期或用方向键选择，**Enter** 确认日期，**Esc** 取消本次日历选择；这两个键在日历中不会保存或关闭任务编辑窗口。月份标题可切换到月份/年份视图。
- 左侧圆圈完成任务；保存成功后显示勾线和淡出，提示中可撤销。提示位于新建按钮上方，悬停/获得键盘焦点时暂停倒计时。
- “已完成”查看历史，切换“全部任务”或“最近删除”编辑、删除与恢复。删除保留 30 天。
- 面板菜单提供收起/展开、设置、提醒记录、隐藏、桌面固定/置顶和退出。
- 托盘单击显示面板，右键打开菜单。关闭输入窗口不会退出后台。

## 桌面与通知

默认固定到 Windows 桌面层；“始终置顶”是可选模式。桌面连接失败时恢复普通窗口并显示提示，菜单可重试。Explorer 重启后会重建托盘与面板。

默认提醒为提前一小时和截止时，默认静音。系统通知包含“打开任务”“稍后 10 分钟”“完成”。延后不会改变截止时间。创建或修改时已经过去的提醒不补发。电脑恢复/程序重新启动时，每项任务只选择最新相关提醒；超过三项汇总。结果不确定的投递不自动重发，在“提醒记录”中可以手动重试。

**系统接受不表示已读。** 横幅与声音遵循 Windows 通知、勿扰模式及组织策略。应用不使用额外弹窗绕过系统设置。“设置”中有测试通知按钮。

退出后不再检查提醒；睡眠时不保证唤醒电脑。再次运行时处理仍然有效的错过提醒。需要长期提醒时，请在设置中自行启用登录启动。

## 数据与恢复

数据在 `%LOCALAPPDATA%\ReMinder\state.json`，本地明文 JSON，应用没有账号、云同步或遥测上传。原子保存与最多七份滚动备份位于 `backups`。磁盘写入失败时不会把操作假装为已保存；损坏数据会尝试最近有效备份，并保留损坏文件。

“设置”支持 JSON 导出/导入，导入先校验并预览冲突。导入不更改本机自启动开关。数据版本较新或没有可恢复备份时采用只读保护，请保留原文件再处理。

可运行 `Uninstall.ps1` 移除当前用户安装、快捷方式、自启动和通知注册，**任务数据保留**。
